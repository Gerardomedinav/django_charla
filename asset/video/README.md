# 🎬 Carpeta de Videos para el Banner (El Restaurante de Django)

Coloca en esta carpeta tu archivo de video de la serpiente verde de Python para el banner principal.

### Nombres de archivo recomendados:
- `banner_python.mp4` (Recomendado)
- `python_snake.mp4`
- `banner.mp4`
- `serpiente.mp4`
- `video.mp4`

### Características sugeridas para el video:
- **Formato:** MP4 (códec H.264 o WebM) para compatibilidad universal en todos los navegadores.
- **Aspect Ratio:** Panorámico (16:9 o 21:9 ultra-ancho), ej: 1920x1080 o 1920x600 px.
- **Comportamiento:** El reproductor web del banner lo reproducirá automáticamente en bucle infinito (`autoplay`, `loop`, `muted`, `playsinline`).
